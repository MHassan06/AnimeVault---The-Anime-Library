AnimeVault

A personal anime collection manager that I built with Python.

AnimeVault is a simple command-line application that allows users to organize their anime collections into three categories: Watched, Anticipated, and Bucket List.

I developed this project to practice Python programming, functions, data structures, file handling, and JSON data persistence.

Features:


   - Watched: Keep track of anime you've already watched.

   - Anticipated: Organize upcoming anime you're looking forward to.

   - Bucket List: Maintain a collection of anime you plan to watch.

   - Add Entries: Add new anime titles to any category.

   - Remove Entries: Remove titles from your collections.

   - Replace Entries: Update existing titles.

   - Data Persistence: Automatically save your collections using JSON.

   - Input Validation: Handle invalid menu selections and entry numbers.
	

Technologies Used:

   - Python 3.

   - JSON.

   - File Handling.

   - Functions and Loops.

   - Lists and Dictionaries.


Getting Started Requirements:

   - Python 3.x
	

Installation:

   - Download or clone this repository.

   - Extract the project files if downloaded as a ZIP.

   - Open a terminal in the project directory.

   - Run the application: python AnimeVault.py

   - On Windows, you can also try: py AnimeVault.py


Data Storage:

AnimeVault uses a JSON file to store collection data locally.

The data is loaded when the application starts and saved whenever changes are made. If no existing data file is found, the application creates an initial collection structure.
